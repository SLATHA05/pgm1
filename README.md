# Assignment: Travel Company Profit Calculator

## Objective

Write a Python program to calculate the profit earned by a travel company.

### Problem Statement

A travel company wants to fly a plane to Coimbatore.

- Flight Cost = 5000 dollars
- Number of Passengers = 29
- Ticket Price = 200 dollars

### Tasks

1. Create variables for the above values.
2. Calculate the total revenue.
3. Calculate the profit.
4. Display the profit.

### Formula

Revenue = Passengers × Ticket Price

Profit = Revenue − Flight Cost

---

### Expected Output

```
Profit: 800
```
